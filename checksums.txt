Note: hashes above correspond to a local electron-builder run. If you rebuild

GitHub release.

The installer artifact name is fixed (RetroVault-Archive-Manager-Setup.exe, no
spaces, no version number) via nsis.artifactName in package.json, matching the
portable build, so the GitHub Pages site's direct download links stay valid
across releases.

Known issue: the portable .exe's self-extracting launcher does not always
terminate all child processes when the window is closed (confirmed via
testing - the installed/unpacked build closes cleanly, the portable one can
leave background processes running). Prefer the installer if you hit
unexplained memory pressure after repeated launches.
