The installer artifact name is now fixed (IA-Item-Manager-Setup.exe, no
spaces, no version number) via nsis.artifactName in package.json, matching
the portable build. This keeps the GitHub Pages site's direct download link
valid across releases - GitHub silently turns spaces in uploaded asset names
into dots (e.g. the v2.0.0 release's installer briefly ended up as
"IA.Item.Manager.Setup.2.0.0.exe"), which broke direct linking before.
